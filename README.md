# India CPI Inflation Analysis

## Project Overview
This project analyzes India's Consumer Price Index (CPI) inflation using Microsoft Excel and Power Query. It includes data preparation, analysis, and charts to explore inflation trends and present the findings visually.

## Objectives
- Analyze CPI inflation data.
- Explore trends and patterns in the available data.
- Use charts to communicate analytical findings.
- Organize the analysis to support data-driven understanding.

## Tools & Technologies
- Microsoft Excel
- Power Query
- Data Cleaning and Transformation
- Data Analysis
- Charts and Data Visualization

## Project Files
- Excel workbook containing the CPI analysis and charts.
