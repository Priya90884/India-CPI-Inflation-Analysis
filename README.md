# India CPI Inflation Analysis

## Project Overview
This project focuses on analyzing India's Consumer Price Index (CPI) and understanding inflation trends over time. The objective is to explore changes in inflation and present the findings through clear data analysis and visualizations.

## Objectives
- Analyze CPI and inflation trends over time.
- Identify periods of rising or falling inflation.
- Compare inflation trends across available categories.
- Present findings to support data-driven understanding.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Obtain a reliable CPI dataset.
2. Clean and prepare the data.
3. Perform exploratory data analysis (EDA).
4. Create visualizations of inflation trends.
5. Summarize findings and insights.
